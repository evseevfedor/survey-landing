# survey-landing
# Dotazník pro prodej nemovitosti  
### MBA Research Project | Ing. Fedor Evseev

Minimalistická jednostránková webová prezentace určená k distribuci anonymního dotazníku v rámci závěrečné práce MBA.

Projekt je zaměřen na výzkum očekávání lidí při prodeji nemovitosti a sběr primárních dat prostřednictvím Google Forms.

---

## 🎯 Cíl projektu

- Zvýšit kvalitu akademického výzkumu založeného na reálných datech  
- Analyzovat rozhodovací procesy vlastníků nemovitostí  
- Identifikovat klíčové faktory při výběru realitních služeb

- GitHub Pages (deployment)

Bez frameworků, bez build procesu.
