# Dotazník pro prodej nemovitosti (MBA výzkum) | Ing. Fedor Evseev

Jednostránkový web (landing page) s výzvou k vyplnění anonymního Google Forms dotazníku.  
Cíl: získat odpovědi pro MBA závěrečnou práci zaměřenou na očekávání lidí při prodeji nemovitosti.

## Live stránka
- GitHub Pages: `https://USERNAME.github.io/REPO/`

## Co je uvnitř
- `index.html` – obsah stránky + SEO meta tagy (title, description, OG)
- `style.css` – neo-brutalism styling, mobile-first, 1 sloupec
- `script.js` – mikro-interakce tlačítka (hover/click efekty, shine/ripple)

## Nastavení (GitHub Pages)
1. Repo → **Settings**
2. **Pages**
3. Source: **Deploy from a branch**
4. Branch: **main** / Folder: **/(root)**
5. Uložte, otevřete URL z GitHub Pages

## Důležité: upravte před publikací
V `index.html` nahraďte:
- `https://USERNAME.github.io/REPO/` (canonical + OG URL) za skutečnou adresu vašeho GitHub Pages webu.
